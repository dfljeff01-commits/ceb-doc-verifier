# 数据核对模块v1 测试夹具（脱敏）

本目录存放"数据核对模块"（班列统一编号 + 联运结算/补贴对账）的回归测试夹具。

## 文件

- `datacheck_trips_v1.json`：9 条班列记录 + 期望编号 + 代码字典。
  覆盖任务书 §一 的核心回归用例：**2025-10-10 同日同线路的临开（L）与图定（T）
  两趟班列必须生成两个不同编号**（`20251010-PW-MZL-RU-L` / `20251010-PW-MZL-RU-T`）。

## 脱敏口径（任务书交付要求 §4）

- **不含任何真实企业主体名称**；货物品名为通用品类名（汽车零配件/光伏组件等）。
- **结算合计 = 真实台账值 − 300,000.00**：十进制常数平移精确无损，
  数值之间的大小、差值、相等关系与真实数据完全一致，可驱动同一套核对逻辑。
- **补贴字段**：结构等价的合成值；其中记录 7/8/9（10-05、10-10临、10-10图）的
  `ly_advance_100` 保留"三条相邻记录数值完全相同"的真实数据质量问题结构
  （真实值 `567834.014285714` 平移为 `267834.014285714`），
  用于重复值检测的专项回归（系统应恰好命中这三条记录的该字段）。

## 使用

- 纯逻辑测试/自测：`python selftest.py`（读取本 JSON 断言 9 条编号回归等）；
- API/DB 测试：`pytest test_datacheck.py -v`（按夹具 records 建班列并核对）。
