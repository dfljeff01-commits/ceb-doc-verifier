# 班列单证核验 App · 安装与演示说明（Android 侧载版）

> 本 App 为 **Flutter 构建的 Android 演示版**，通过**侧载（sideload）安装**演示，
> 未上架任何应用商店。APK 未做正式发布签名（使用 Flutter 默认 debug 签名的 release 构建）。

## 一、文件位置

- APK：`mobile_app/build/app/outputs/flutter-apk/app-release.apk`
- 演示用单证图片（放手机相册）：`sample_pdfs/images/clean/`（5张，全部正确）、
  `sample_pdfs/images/issues/`（4张，含问题）

## 二、传输与安装

### 方式A：扫码下载（推荐，现场最方便）

在**后端电脑**上执行（项目根目录）：

```bash
# 1. 启动API后端（手机App要连它）
uvicorn api:app --host 0.0.0.0 --port 8000

# 2. 启动APK下载服务（端口8001，serve_apk.py 在项目根目录）
python serve_apk.py
```

用手机扫描 `apk_qrcode.png`（由 `serve_apk.py` 自动生成在项目根目录）即可下载安装。
二维码指向本机局域网地址（如 http://192.168.5.44:8001/app-release.apk），**手机与电脑必须同一Wi-Fi**。

### 方式B：USB / 聊天工具传输

1. USB 连接手机 → 把 `app-release.apk` 拷到手机（或用微信/钉钉"文件传输助手"发给自己）。
2. 在手机上点击 APK → 系统会提示"不允许安装未知来源应用"。

### 开启"允许安装未知来源"（各品牌路径）

| 品牌 | 路径 |
|---|---|
| 小米/Redmi | 设置 → 隐私保护 → 特殊权限 → 安装未知应用 → 选择来源（如"文件管理"）→ 允许 |
| 华为/荣耀 | 设置 → 安全 → 更多安全设置 → 安装外部来源应用 → 选择来源 → 允许 |
| OPPO/一加 | 设置 → 安全 → 安装未知应用 → 允许 |
| vivo | 设置 → 安全 → 安装未知应用 → 允许 |
| 三星 | 设置 → 应用 → 特殊访问 → 安装未知应用 → 允许 |
| 原生/Pixel | 弹窗时直接点"设置"→ 允许该来源 |

3. 回去点击 APK → 安装 → 打开"班列单证核验"。

## 三、演示前配置（必做）

1. 打开 App → 右上角 ⚙️ 设置 → 填入**后端电脑的局域网IP**（如 `http://192.168.5.44:8000`）→ 保存。
   - 查电脑IP：`ipconfig` 看"无线局域网适配器 IPv4 地址"
   - 后端必须以 `--host 0.0.0.0` 启动（见上），手机与电脑同一Wi-Fi。
2. 把 `sample_pdfs/images/` 下的演示单证图片导入手机相册。

## 四、演示脚本（建议照此走）

1. **相册多选** clean 组 5 张（发票/箱单/运单/报关单/产地证）→ 上传识别 → 查看提取字段
   → 点"开始核验" → **大圆环风险分 0，低风险（绿色）**，11 项全过 → 证明不误报。
2. **相册多选** issues 组 4 张 → 核验 → **风险分 100，高风险（红色）**：
   缺产地证 / 品名不一致（语义相似度0.55）/ 箱数475≠480 / 毛重超1%容差，
   每项有 AI 修正建议。
3. **现场纠错演示**：回到已识别单证列表 → 点开出口报关单卡片 → 把件数改成 480、
   品名改成"陶瓷卫浴洁具" → 保存 → 重新核验 → **风险分实时下降（100→…）**，
   证明"识别错误可人工纠正"闭环。
4. **真实拍照**：拿任一单证打印件或屏幕显示拍照 → 走同一流程（识别效果取决于拍摄清晰度）。
5. （可选）错误处理演示：设置里故意填错IP → 操作时弹出明确错误提示，不崩溃不白屏。

## 五、已知限制（诚实性）

- 演示版未上架商店、未正式签名；仅用于竞赛演示。
- 识别依赖后端 tesseract OCR（中文），扫描/拍照质量差时个别字段会识别错——
  这正是 App 保留"字段人工纠正"环节的原因（与Web端设计一致）。
- 无用户系统/历史记录；后端地址需手动配置。
