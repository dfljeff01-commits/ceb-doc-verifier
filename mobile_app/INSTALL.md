# 班列单证核验 App · 安装与使用说明（Android 初级版）

> 本 App 为 **初级版（内部试用）**，通过**侧载（sideload）安装**，
> 未上架任何应用商店。APK 未做正式发布签名（使用 Flutter 默认 debug 签名的 release 构建）。

## 一、文件位置

- APK：`mobile_app/build/app/outputs/flutter-apk/app-release.apk`
- 试用用单证图片（放手机相册）：`sample_pdfs/images/clean/`（5张，全部正确）、
  `sample_pdfs/images/issues/`（4张，含问题）

## 二、传输与安装

### 方式A：扫码下载（推荐，现场最方便）

在**后端电脑**上执行（项目根目录）：

```bash
# 1. 启动API后端（手机App要连它）
uvicorn api:app --host 0.0.0.0 --port 8000

# 2. 启动APK下载服务（端口8001，serve_apk.py 在项目根目录）
python serve_apk.py
```

用手机扫描 `apk_qrcode.png`（由 `serve_apk.py` 自动生成在项目根目录）即可下载安装。
二维码指向本机局域网地址（如 http://192.168.5.44:8001/app-release.apk），**手机与电脑必须同一Wi-Fi**。

### 方式B：USB / 聊天工具传输

1. USB 连接手机 → 把 `app-release.apk` 拷到手机（或用微信/钉钉"文件传输助手"发给自己）。
2. 在手机上点击 APK → 系统会提示"不允许安装未知来源应用"。

### 开启"允许安装未知来源"（各品牌路径）

| 品牌 | 路径 |
|---|---|
| 小米/Redmi | 设置 → 隐私保护 → 特殊权限 → 安装未知应用 → 选择来源（如"文件管理"）→ 允许 |
| 华为/荣耀 | 设置 → 安全 → 更多安全设置 → 安装外部来源应用 → 选择来源 → 允许 |
| OPPO/一加 | 设置 → 安全 → 安装未知应用 → 允许 |
| vivo | 设置 → 安全 → 安装未知应用 → 允许 |
| 三星 | 设置 → 应用 → 特殊访问 → 安装未知应用 → 允许 |
| 原生/Pixel | 弹窗时直接点"设置"→ 允许该来源 |

3. 回去点击 APK → 安装 → 打开"班列单证核验"。

## 三、使用前配置（必做）

1. 打开 App → 右上角 ⚙️ 设置 → 填入**后端电脑的局域网IP**（如 `http://192.168.5.44:8000`）→ 保存。
   - 查电脑IP：`ipconfig` 看"无线局域网适配器 IPv4 地址"
   - 后端必须以 `--host 0.0.0.0` 启动（见上），手机与电脑同一Wi-Fi。
2. 把 `sample_pdfs/images/` 下的示例单证图片导入手机相册。

## 四、试用流程（建议照此走，核心路径三步：打开App → 拍照 → 看到一句话反馈）

1. **拍照即传**：首页点"拍 照 上 传"（或"从相册选择"多选 clean 组 5 张）→
   照片先过本机质量把关（模糊/过暗/边框遮挡/分辨率过低会提示"请重新拍摄"，不上传）→
   自动上传，随后首页出现**一句话反馈大横幅：风险等级（红/黄/绿）+ 一句关键问题 + 批次编号**。
   - clean 组 5 张全部正确 → **绿色横幅**："全部检查项通过，未发现问题"；
   - issues 组 4 张（含问题）→ **红色横幅**：提示最关键的问题（如缺少必需单证）。
2. **回电脑端看完整报告**：在电脑端核验网页选择"📱 手机拍摄批次"→ 输入横幅上的
   **批次编号**（形如 MB-20260920-143001-8A3C，可点复制按钮）→ 查看该批次的
   完整核验明细、风险分数构成与AI建议（复杂处理与展示只在电脑端做）。
3. **现场速查**：在"现场速查"卡输入运单号/单证编号/批次编号 → 一键查这批货
   **之前是否核验过、上次的风险等级与核心结论**（人在现场随手查，不用跑回电脑）。
4. **弱网体验**：设置里故意填错IP（或开飞行模式）→ 拍照后横幅提示
   "N 张照片等待上传（网络恢复后自动重试）"，照片不丢、App不卡死；
   恢复网络/改回正确IP后 App 自动补传（也可点 🔄 立即重试）。
5. **真实拍照**：拿任一单证打印件拍摄走同一流程（识别效果取决于拍摄清晰度；
   模糊/过暗照片会在本机被拦截，不会浪费后端处理）。

## 五、已知限制（诚实性）

- 初级版未上架应用商店、未正式签名，仅供公司内部试用；正式发布需 release 签名与版本管理。
- 识别依赖后端 tesseract OCR（中文），扫描/拍照质量差时个别字段会识别错——
  App 不做字段编辑：需要在电脑端"手机拍摄批次"报告中查看明细，确需纠正时
  在电脑端网页补齐字段或重新拍摄上传。
- 扫码查询（扫单证条码/二维码触发速查）为 P1 规划项，本轮未实现。
- 后端地址需手动配置；本地"最近反馈"仅缓存最近20条摘要（不含完整报告）。
